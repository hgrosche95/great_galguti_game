# Great Galguti – Web-UI

Die spielbare Oberfläche des Spiels (React + Vite + TypeScript). Login/Registrierung, Warteraum und Partie; verbindet sich per REST (`/auth`) und WebSocket mit dem Server aus `../server`.

```bash
npm install
npm run dev     # http://localhost:5173, erwartet den Server auf localhost:8080
npm run lint
npm run build
```

Mehr zu Aufbau, Regeln und Deployment steht in der [Haupt-README](../README.md).
